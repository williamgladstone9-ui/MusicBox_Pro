# ⛵ BoatBox Boat Installation Notes

## Best Physical Setup

```text
iPhone 5c          iPhone 5s
 Remote             Captain / Spotify source
    \                 /
     \ WiFi BoatBox  /
      \             /
       Surface RT running postmarketOS
          |
          | 3.5mm headphone / AUX cable
          v
       Boat stereo AUX input
          |
          v
       Boat speakers
```

## Why This Is Better for a Boat

- The boat stereo is much louder than iPhone speakers.
- Only one audio path means fewer sync/delay problems.
- iPhones can stay dry/safe and act as remotes.
- Surface can sit near the stereo/AUX input.
- Offline mode works away from shore.

## Recommended Roles

### Surface RT

- Boat WiFi AP
- Music server
- Spotify Connect receiver when online
- AirPlay receiver for Spotify offline from iPhone
- 3.5mm AUX output to boat stereo

### iPhone 5c

- BoatBox Remote home-screen app
- Big controls only
- Good for passengers/crew

### iPhone 5s

- BoatBox Captain home-screen app
- Spotify source
- Music uploads
- Source/network controls

## AUX Gain Staging

Start safe:

1. BoatBox volume: 35-45%
2. Boat stereo volume: low
3. Play music
4. Raise boat stereo volume
5. If distorted, lower BoatBox volume first

Use MUTE before plugging/unplugging AUX.

## On-Water Reliability Tips

- Use Offline Library mode for maximum reliability.
- Download Spotify playlists before leaving shore.
- Use AirPlay mode for Spotify offline.
- Set both iPhones Auto-Lock longer while boating.
- Add BoatBox apps to home screen before leaving shore.
- Keep the Surface shaded/ventilated.
- If voltage/power is unstable, pause music before starting the boat engine.
